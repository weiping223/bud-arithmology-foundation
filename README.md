# Bud Arithmology: A Set-Theoretic Foundation via Germs and Projection

> **Status:** exploratory draft · open to criticism · not a claim of consistency proof

This repository contains a foundational proposal that attempts to:
- treat numbers as **typed set-numbers** with generation depth,
- introduce an **embryonic germ** `ϑ` as a pre-set object,
- separate **internal equality** (`≃`) from **classical extensional equality** (`=`),
- and recover classical arithmetic via a **controlled projection** `π`.

The goal is **not** to overthrow Peano arithmetic, but to explore whether a
“germ → projection → classical reset” architecture can coherently extend it.

## 🧠 Key Ideas (Very Briefly)

1. **Germ (ϑ)** — a two-leaf / Möbius-like object where `0 ≃ 1` holds *only internally*.
2. **Projection (π)** — a forgetful map that resets germ structures to classical numbers.
3. **Set-Numbers** — numbers are typed sets with depth and projection.
4. **Depth as Invariant** — recursive depth is *not* cardinality or ordinal.
5. **No Prime Definition (Yet)** — prime theory is explicitly left as an interface.

## ⚠️ What This Is Not

- ❌ Not a proof of consistency relative to ZF
- ❌ Not a new prime formula
- ❌ Not a claim that `0 = 1` in classical logic

---

## ✅ What This Tries to Be

- A **structurally explicit** alternative starting point
- A **layered semantics** for “revolution + extension”
- A **testable framework**: can this be modeled in ZF?

# FORMAL-PROOF.md — Bu-Arithmetic Structural–Deviational Equivalence

> **Status:** internal formal derivation (exploratory draft) · not peer-reviewed
> **Scope:** this proof is carried out **entirely inside the Bu-arithmetic framework**
> (Axioms A1–A3 + the three operations + the four deviational functions).
> **It does not invoke** any classical transcendence theorem
> (Hermite, Lindemann, Siegel–Shidlovsky, Baker, etc.).

This document records the first non-trivial **internal theorem** of Bu Arithmetic:
a computable classification of sequences by their generative structure and the
boundedness of their associated deviational functions.

---

## 0. One-paragraph summary

Bu Arithmetic begins from a dialectical base (A1–A3) and defines
**three operations** (生 shēng / 筛 shāi / 合 hé) together with
**four deviational functions** (四幻: 频 F, 间 G, 模 P, 周 C).
This proof establishes that, for any sequence generated by Bu operations, the
following are equivalent:

> **The structure contains "筛部无限" (infinite sieving) or "合无" (unbounded merging)**
> ⇔
> **At least one of the four deviational functions is unbounded.**

The forward direction is explicit construction; the reverse direction is
structural induction. Both stay inside the Bu framework.

---

## 1. Axiomatic base

**Axiom A1 (Infinite generation).**
`1 / 0 = ∞`.
Reciprocation is a generative act: from zero (nothingness), infinity is born.

**Axiom A2 (Infinite differentiation).**
`∞ → ∞ → −∞`.
Infinity can differentiate into mutually orthogonal directions; products of
distinct directions vanish.

**Axiom A3 (Zero–infinity duality).**
`0 ↔ ∞`.
Zero and infinity are not opposites; they are two faces of one structure.

On this base we define:

- **Operations (三幻)** — each may be *deterministic* or *random*:
  - 生 (shēng, generate)
  - 筛 (shāi, sieve)
  - 合 (hé, merge)
- **Deviational degree (四幻)** — each is either `定` (bounded) or `无` (unbounded):
  - 频 F (frequency)
  - 间 G (gap / interval)
  - 模 P (modular / scale)
  - 周 C (periodicity)

---

## 2. The proposition to prove

### Theorem (Deviation–Structure Equivalence)

> For every sequence generated by Bu operations, the following are equivalent:
>
> **(S)** The structure contains {筛部无限, or 合无}.
>
> **(D)** At least one of the four deviational functions is `无` (unbounded).

The proof has two halves:

- **Forward (S → D)** — Lemma 2: an unbounded operation produces an unbounded
  deviation function.
- **Reverse (D̄ → S̄)** — Lemma 3 (contrapositive): if all four deviations are
  bounded, then the structure is finite / bounded.

No classical transcendence theorem is used in either half.

---

## 3. Forward direction: unbounded operation → unbounded deviation (Lemma 2)

### Lemma 2.1 — 筛部无限 → 间无

Take positions from `N` at factorial locations (Liouville-type):
`pos(k) = k!`.

Then the gap function:

```
G(k) = pos(k) − pos(k − 1)
     = k! − (k − 1)!
     → ∞
```

So **间 (G) is unbounded (无)**.

Numerical values:
`G = [1, 4, 18, 96, 600, 4320, …]` — strictly increasing. ✅

---

### Lemma 2.2 — 合无 (non-periodic) → 频无

Add non-periodic blocks by the rule `1, 2, 1, 2, …`; alternate block contents
between A and B.

Then the frequency function F(n) for factor A oscillates between `2/5` and
`1/3`:

```
limsup F ≠ liminf F
```

so **频 (F) is unbounded in the sense of non-convergence (无)**.

Numerical check: difference `2/5 − 1/3 = 0.067 > 0`. ✅

---

### Lemma 2.3 — 合无 (general) → 间无 / 周无

Add positions at exponentially growing `2n`-type intervals.

Then the gap function grows exponentially:

```
G(k) = 2^k → ∞    ⇒   间无 (G unbounded)
```

and because the intervals follow no regular law,

```
C is aperiodic      ⇒   周无 (C unbounded / undefined period)
```

Numerical values: `G = [2, 4, 8, 16, 32, 64, …]`. ✅

---

## 4. Reverse direction: bounded deviation → finite structure (Lemma 3)

### Lemma 3 (Boundedness preservation)

> If the base sequence has all four deviations bounded (`定`), and we apply
> only {生(deterministic), 筛全, 合限}, the resulting sequence still has all
> four deviations bounded.

**Proof (structural induction).**

- **Base case.** The basic factors (odd, even, prime) are generated by
  deterministic rules, so all deviations are bounded.

- **Inductive step.** Assume current deviations are all bounded. Examine one
  operation:

  | Operation | Effect on distribution | Deviation status |
  |-----------|------------------------|-----------------|
  | 生 (deterministic) | generates a deterministic basic sequence | preserved |
  | 筛全 | takes the whole sequence, no redistribution | preserved |
  | 合限 | finite additions, changes only a finite prefix | preserved |
  | 筛部 (finite / infinite) | selects a proper subsequence, breaks uniformity → gaps lose bound | **not preserved** |
  | 合无 (periodic / non-periodic) | infinite additions, pattern complexity and period escape control | **not preserved** |

  The inductive step shows:

  - Under {生, 筛全, 合限}, the four deviations remain `定`.
  - Once 筛部无限 or 合无 appears, a deviation becomes `无` (by Lemma 2).

Therefore, by contraposition:

> **All four deviations bounded ⇒ structure ⊆ {生(deterministic), 筛全, 合限}**
> (i.e. no 筛部无限 and no 合无.)

✅

---

## 5. Proof of the main theorem

**Theorem (Deviation–Structure Equivalence).**

- **(→) Forward.** By Lemmas 2.1–2.3: whenever the structure contains
  筛部无限 or 合无, we can construct at least one unbounded deviational
  function. Hence at least one of the four is `无`.

- **(←) Reverse (contrapositive).** By Lemma 3: if all four are `定`, then
  the structure contains neither 筛部无限 nor 合无.

Both directions hold, so the equivalence is proved. ∎
